Project For Next Year

Last month I started getting really into computer logic and architecture, partially thanks to a game called Turing Complete(highly recommend). There is a difference between knowing and understanding, a concept impressed upon me when I was originally pursuing my degree in education; As I've been on my deep dive, learning about the actual mechanics behind how computers work and all the problems we've had to solve to get to where we are today, it reminds me that I know very little, and understand even less, and that excites me.

I'd like, as a big project for next year, to make my own computer, I plan on using the amazing guide made by Ben Eater as a reference but intend to try to make it as much my own as possible, I find following guides one for one isn't always conducive to learning. Regardless I expect this to be an expensive endeavor, both in regards to time and money, I'm getting myself a soldering setup this month and some components to mess around with on a breadboard aswell. At the very least even if I can't make use of the soldering iron for the project anytime soon, it's a useful skill to have and I'm hoping I'll finally be able to fix one of my old broken monitors that has a cold start issue.
